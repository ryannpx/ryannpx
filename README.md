# Hi, I'm Ryann 👋

I'm a Computer Science student at Brigham Young University passionate about building software that makes technology intuitive, meaningful, and enjoyable to use.

Currently, I work as an Undergraduate Research Assistant in the BYU Family History Technology Lab, where I develop front-end and back-end features for Relative Finder, a genealogy platform used by thousands of users. My work combines software engineering with Human-Computer Interaction (HCI), user research, and UI/UX design to create experiences that help people connect with their family history.
